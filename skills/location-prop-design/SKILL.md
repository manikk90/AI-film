# Location and prop design

Inputs: scene breakdown, treatment, existing world references and planned action. Follow the [SOP](../../docs/SOP.md) and [asset contract](../../docs/CONTRACT.md).

Create a scene-indexed inventory of required locations and important props. Consolidate repeated locations before generating images. Separate time/weather/damage variants from entirely new places.

Define entrances/exits, windows, light sources, furniture positions, action zones and reverse-angle relationships. Specify how characters can move through the space. Produce establishing and reverse-angle references only where the shots need them. Check the actual images for consistent geography.

For story-critical props, define appearance, scale, material, markings and state. Track ownership and transitions (table -> right hand -> unfolded -> right pocket). Distinguish duplicates explicitly. Group incidental dressing under the location instead of creating unnecessary standalone assets.

Register inspected image files with immutable IDs and derivation links. Supply a location-layout note and prop state table. If generation is unavailable, provide the briefs and missing-image list without claiming completion. A location name in a prompt does not replace binding the actual intended image.
