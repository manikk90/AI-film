## Attention around stable blocking

Define first read, necessary secondary evidence and deliberately withheld information. Check the frame at intended viewing size; inspect anatomy/contact separately. Thumbnail readability cannot prove full correctness. Avoid tangencies at story-bearing faces, hands and objects.

Use the composition family in the catalogue selectively. Negative space can establish arrival; nested frames can express access; depth can show unequal information. Choose the relationship before its pattern name.

Keep world-space blocking across angles. If A stays by a window and B by a doorway, camera reversal may exchange screen order while both remain fixed. Visible wall and location-angle binding must match that camera. Do not reuse a front-wall binding for a reverse merely because the room name matches.

## Two-shots and over-shoulders

| Option | Relationship | Specify | Failure |
|---|---|---|---|
| Clean two-shot | Shared participation/exchange | Readable bodies, hands and shared space | Exchange hidden between bodies |
| Offset profiles | Confrontation with space | Feasible lateral view, coherent eyelines | False same-direction gaze |
| Dirty OTS | Listener shares the exchange | Small relevant shoulder/head edge, sharp speaker | Invented third foreground person |
| Near soft edge | Intimacy/proximity | Partial silhouette, controlled blur, clear main face | Blur covers mouth/contact |
| Deeper two-shot | Separation/unequal knowledge | Primary near/mid, meaningful secondary deeper | Necessary response unreadable |
| Shared-depth OTS | Speech and reaction both matter | Enough detail on both relevant planes | Automatic shallow DOF hides the beat |
| Negative-space relation | Waiting/absence | Space toward an established route/partner | Arbitrary empty area |
| Reflection/opening | Simultaneous readings | Verified geometry and sightline | Impossible reflection/duplicate identity |

Do not blur every OTS. Use a foreground fragment only if its owner belongs there and it helps. Do not demand a full face/costume for a shoulder crop. Retain the relevant owner binding. Remove cast outside this shot even if they occur elsewhere in the scene.

**Schematic phrase:** "Static MCU on [approved speaker tag] in [exact approved view]; [approved listener tag]'s soft shoulder fills a narrow left edge; speaker's mouth and eyes unobstructed." Square-bracket fields are teaching placeholders, not executable tags.

## Camera decisions

- Describe relationships before optional focal length. Perspective depends on camera position; focal length interacts with format and framing.
- Specify height relative to the action: seated eye-line, hand-level, floor-level or actual overhead. Low angle does not authorise stretched bodies/objects.
- Choose high/low views for information or felt relationship, not automatic high=weak/low=heroic formulas.
- Keep static cameras static. For video give one feasible motivated movement and retain a supplied first frame. A move cannot invent reference-unverified architecture.
- Select one still instant. Put trajectories, rack focus and sequential action in video, not an impossible multi-time still cell.
- State primary focus and other planes that must remain readable. Separate anatomical left/right from screen-left/right.

## Lighting decisions

Separate source, direction, apparent source size/softness, contrast/fill, colour relationship and exposure/finish. "Cinematic" is insufficient.

| Option/dimension | Operational rule | Failure |
|---|---|---|
| Motivated daylight | Map sun/sky/window/shade | Key flips between angles |
| Practical-led night/interior | Locate actual emitter and falloff | Invented fixture in locked frame |
| Hard source | Use crisp shadows purposefully | Required facial/action evidence lost |
| Broad soft source | Define apparent source size | Equate softness with low contrast |
| Front/near-axis | Prioritise clear graphic read | Unintended flatness |
| Side/cross | Shape form/surface from plausible source | Arbitrary alternate key side |
| Back/rim | Derive edge from source | Unmotivated glowing outline |
| Top | Respect sun/fixture geometry | Eyes lost when expression is essential |
| Under | Require explicit unusual source/design | Automatic horror coding |
| High-key | Broad tonal readability | Assume brightness means happiness |
| Low-key | Select information in darker field | Hide mandatory evidence |
| Mixed temperature | Map which source reaches each surface | Random warm/cool patches |
| Patterned/gobo | Use actual leaves/grille/design | Invent foliage to justify beams |
| Bounce/fill | Respect reflecting surfaces/locks | New unexplained illumination |
| Negative fill | Subtract return in unlocked setup | Add a black object to the image |
| Silhouette | Preserve required contour/action | Hide the required expression |
| Atmosphere/volumetric | Require supported medium/source | Unrequested smoke/dust for spectacle |

Portrait labels such as split, loop, Rembrandt and butterfly describe useful arrangements in controlled portraits. Translate them into source geometry and readable features rather than universal film-scene prescriptions. Preserve identity/skin texture.

For an unlocked design compare meaningful alternatives, such as soft window intimacy and harder spatial division. Treat effectiveness as untested until inspected. For strict fm/fc retain the source lighting. A palette approval does not authorise changing sun direction.

## Sequence connections

Plan cause before response; establish necessary geography and preserve possession/contact. A detailed request expands preparation, decisive action, reaction and consequence where meaningful; it does not expand each cell's cast inventory.

For graphic matches specify shape, screen position, scale and actual cut point in the pair. For action matches specify phase/direction. Shared colour can be a motif without being a usable match cut. J/L cuts are audio overlaps; label source and onset/continuation without adding an invisible speaker visually. These remain proposed edits until tested on actual media.

Develop motifs through approved recurrence. Do not invent a new prop/scene to finish a visual pattern. Keep edit relations in edit notes or relevant video/audio instructions, not as unrelated tags in a still prompt.
