## Separate review passes

Use applicable passes; one score cannot cancel a hard failure.

| Pass | Ask | Evidence/failure |
|---|---|---|
| Source and scope | Is this the requested beat/artifact? | Approved text, requested frames and latest scoped corrections |
| Identity and binding | Exact person/look/prop/view? | Inspected references plus approved registry; no invented tags |
| Depiction | What is actually visible? | Cast count, hand owners, contact, crop, readable action, anatomy |
| Meaning | Does visible evidence support the intended inference? | Separate proposed reading from observed audience evidence |
| World coherence | Do geometry, scale, material and light agree? | Stable layout, reciprocal views, source direction, support |
| Sequence | Are cause, response, possession and entry/exit continuous? | Actual ordered frames/clips and transitions |
| Prompt locality | Does every tag/direction belong to this shot? | No global cast inventory, unrelated future beats or wrong angle |
| Delivery | Is the requested artifact provided and usable? | Actual media if requested, correct ratio/copy, dialogue last |

For strict source work, compare unchanged fields explicitly: camera/crop, staging, lighting, background, identity, wardrobe and prop state. For video inspect start, decisive action, intermediate transitions and end; do not infer temporal success from a still contact sheet alone.

## Diagnose failure before repair

| Failure | Likely issue | Smallest useful repair |
|---|---|---|
| Pretty image, wrong idea | Intended relation absent/ambiguous | Change mechanism or visible evidence within authorised scope |
| Correct objects, unreadable exchange | Occlusion, timing or focus | Adjust eligible view/focus/action instant |
| Extra person/prop | Global context leaked into local prompt | Remove unrelated binding/inventory |
| Wrong shoulder/hand owner | Missing binding/contact specification | Bind the actual fragment/owner and retain anatomy |
| Inconsistent reverse | World rearranged or wrong local view | Restore fixed positions and map actual reverse |
| False material | Texture without construction/light behaviour | Fix reflectance, joins, grain, support and source interaction |
| Region feels generic | Stereotype kit | Revisit locality/function evidence, preserve approved parts |
| Lighting changes in fc | Default style overrode strict source | Restore source light; edit only requested fields |
| Decorative blur hides emotion | Pattern selected before story | Reduce/remove blur or choose readable geometry |
| Match cut does not connect | Only a loose thematic link | Specify actual geometry/phase or use another transition |
| Campaign fragments | No invariant system | Define fixed relation and controlled variables |
| Exact copy/dialogue wrong | Image/readability mistaken for textual verification | Compare exact text; repair copy alone if possible |

Do not solve a failure by deleting source requirements, changing cast identity or moving locked objects. If the required design cannot be executed with available capabilities, preserve the concrete design and state what execution is pending.

## Check the actual requested artifact

- **Prompt-only:** inspect tags, locality, action, source constraints and formatting. Report only a text/plan check.
- **Image:** inspect actual output at useful scale plus story-bearing details. A tool success is not image acceptance.
- **Video:** inspect actual clip for timing, identity/state drift, contact, camera and action coverage; listen to assigned audio. Sampling limits must remain explicit where they affect conclusions.
- **Poster:** inspect final size/crop, exact approved copy, hierarchy and output resolution.
- **Skill:** validate structure/links and apply it to realistic tasks. A documentation or forward test does not prove generated-media quality.

## Adoption and completion claims

Keep source fact, user requirement, proposed transfer and observed test result separate. A critic's blue-ink reading is not a universal colour law. A professional case study is not commercial performance evidence. The 40 techniques are a nonexclusive working library, not all possible types.

If learning is requested, persist scoped reusable corrections through available authorised storage and verify success. Preserve unrelated rules. Do not create schedules unless requested, or claim a skill runs at night because a learning paragraph exists.

Completion can mean prompt delivered, image edited, skill installed or source saved; name the actual outcome. Keep uninspected media and untested hypotheses pending. Do not claim permanent model training, all-chat access or measured improvement without evidence.
